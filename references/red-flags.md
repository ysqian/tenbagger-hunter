# 避雷清单与卖出信号

> 十倍股的失败往往不是因为"没涨"，而是因为"踩雷"。本节用于给评分卡做**扣分项**校验，并驱动卖出决策。

---

## A. 公司层面避雷点（定性）

| 编号 | 信号 | 为什么危险 |
|---|---|---|
| C1 | **频繁跨界** | 主业不聚焦，什么热门做什么，说明主业缺乏增长或管理层不专注 |
| C2 | **故事大于产品** | 只讲概念、讲叙事，产品与业务缺乏竞争力，无法兑现业绩 |
| C3 | **管理层失信** | 财务造假、承诺跳票、信息披露违规，信任成本不可逆 |
| C4 | **核心竞争力说不清** | 一问核心优势就支支吾吾，护城河无法验证 |
| C5 | **大股东密集减持** | 内部人最了解公司，密集减持往往是对未来信心不足 |
| C6 | **过度依赖单一大客户/单一政策** | 收入结构脆弱，客户流失或政策退坡即失速 |

---

## B. 财报层面避雷点（定量）

| 编号 | 信号 | 判定参考 |
|---|---|---|
| F1 | **扣非净利润差** | 扣非净利润 / 净利润 长期 < 60%，利润靠补贴、处置资产等支撑 |
| F2 | **现金流长期跟不上** | 经营现金流净额连续 2–3 年为负，或长期显著低于净利润 |
| F3 | **商誉过大或频繁并购** | 商誉 / 净资产 > 30%，减值风险高；并购频繁说明内生增长乏力 |
| F4 | **应收账款暴增** | 应收增速持续显著高于营收增速，回款恶化、收入可能虚增 |
| F5 | **存货积压** | 存货增速远高于营收增速，周转天数持续拉长，存在滞销与减值风险 |
| F6 | **资产负债率过高** | 显著高于同业，利息支出吞噬利润，抗周期能力弱 |

---

## C. 卖出信号（四类触发条件）

| 编号 | 信号 | 具体触发条件 |
|---|---|---|
| S1 | **逻辑被证伪** | 支撑买入的核心假设不再成立（如政策转向、技术路线被替代、客户流失） |
| S2 | **成长明显失速** | 营收/利润增速连续 2–3 个季度显著下滑，且非一次性因素 |
| S3 | **估值极度透支** | 估值处于历史极高分位，或 PEG 显著 > 2 且成长未跟上 |
| S4 | **行业趋势恶化** | 行业景气度明显下行、产能过剩、价格战加剧，长期前景变差 |

> 触发任一即进入"减仓评估"；同时触发 ≥2 条，建议执行纪律性减仓。

---

## D. 使用方式

1. 在四维打分完成后，逐条核对 A、B 两组，命中的记入 `red_flags` 列表。
2. 每个命中项在总分上 **−5 分**（最多 −20）。
3. 命中 ≥3 项避雷点 → 评级直接降为 **C**。
4. 持有期复盘时，逐条核对 C 组；同时对照 S 组判断是否需要卖出。

清单可直接填入 `scripts/score_stock.py` 的 `red_flags` 字段（字符串数组，写清信号编号或描述）。
